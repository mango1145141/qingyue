# 轻阅 · 手机网页版 1.4

在线地址：https://kindle-zftrvo.v2.appdeploy.ai/

本版本将桌面版功能整理为适合 iPhone 的简洁界面，不包含「为你推荐」。保留简洁手机布局，邮箱设置增加授权说明与专用安全入口。

## 功能

- 首页：蓝色书本图标、与桌面使用同一组每日一句、书籍／漫画搜索、EPUB 多选导入。
- 底部四个独立页面：导入、我的书架、发送队列、想读清单。
- 修复补齐图片资源登记并整理 EPUB 打包；保留正文、目录、原图，不凭空恢复丢失的图片。
- 修复报告、另存修复版、邮箱直推、iPhone 文件分享及 Amazon 网页发送入口。
- 本机书架保存原书与修复版，支持收藏、分类、搜索、书籍信息修改、目录与文字预览、确认移除。
- 想读支持书籍和漫画，加入／取消反馈；搜索历史仅保存于本机。
- 沿用原 AppDeploy 后端、设备配对、邮箱授权以及邮箱／处理偏好同步。
- 跟随系统或浅／深色主题、大字和减少动效；主题设置仅在本机保存。

## 使用与边界

在 iPhone Safari 打开在线地址。可通过分享菜单「添加到主屏幕」。网站下载的 EPUB 先存入「文件」，再回轻阅导入；手机网页无法读取其他网站的登录状态或自动接收其下载，也不能静默操作 Amazon。已有书库会话由 Safari／网站管理。

本地修复支持 **50 MB 以内**的 EPUB，并限制压缩包解压规模。50–200 MB 文件可以选入并获得发送引导；请先用电脑版检查修复，再在 Amazon 网页手动上传确认。不能宣称手机安全地后台修复任意 200 MB 文件。邮箱发送另受当前邮箱上限限制。

「邮件已提交」指发件服务器接受了邮件，仍需 Amazon 处理；分享菜单完成也不保证 Kindle 收到。浏览器关闭或 iOS 将 Safari 置于后台，检查／上传可能暂停。刷新后恢复本机记录，待确认邮件需先查询结果；发送请求使用持久的请求标识，避免响应丢失后重复寄送。

原书和修复版存入本机 IndexedDB。清理网站数据、浏览器回收空间或私密浏览可能移除文件，重要文件请下载另存。关闭「在本机保存书架」后，新导入的文件仅在当前会话保留。同步只包含邮箱与处理偏好，不包含电子书、想读、历史或外站登录状态。旧版仅存书名的记录会提示重新选入文件。

163 授权获取渠道：网易邮箱大师 → 我 → 邮箱管理 → 选择邮箱 → 第三方登录管理 → 通用授权码。网页端在邮箱设置 → POP3/SMTP/IMAP → 新增授权密码。

首次邮箱授权通过 AppDeploy 安全授权页完成，授权值只保存在后端环境中；本仓库不包含授权码、私有邮箱、设备凭据或用户电子书。更新同一个 AppDeploy app_id `kindle-zftrvo`，避免丢失已配置的环境授权。

## 本地开发

Node.js 20+：

```sh
npm ci
npx tsc --noEmit
npx vite --config vite.local.config.ts
npx vite build --config vite.local.config.ts
```

本地配置使用 `tools/localSdk.ts`，仅预览界面与 EPUB 本机处理，不能调用在线邮箱或配对服务。发布使用 `vite.config.ts`，AppDeploy 自动提供真实的 `@appdeploy/client` SDK。**不要把本地配置或 SDK 替身用作正式发布入口。**

`src/appdeploy.d.ts` 只是 SDK 的编译声明，既不包含实现，也不含授权。后端依赖平台提供的数据库／环境 API，不能当作通用 Node 服务直接运行。

## 发布与验收

`tests/tests.json` 包含五条独立验收流程，覆盖手机修复导出和刷新恢复、队列错误与删除确认、书籍漫画搜索／想读、设置、设备配对与授权错误。不得使用真实用户电子书或寄出真实邮件作为自动验收数据。

本地验收使用 Chromium 的 iPhone 尺寸模拟，不等同于真实 iPhone 或实际 Kindle 收信验证。平台发布后检查 build、e2e、QA 与运行错误，再记录正式发布结果。

## 引用与依赖

每日一句沿用桌面 `ReadingDiscovery.cs` 的公共领域文字、署名和来源链接，按北京时间每日切换。界面书本 SVG 沿用轻阅原图标。JSZip、React、Lucide 等依赖保留各自许可；沿用仓库根目录许可和第三方说明。

### 安全入口维护

维护者为当前配对的工作区与发件地址生成 AppDeploy 一次性授权页，再用受配对凭据保护的 `/api/mail/authorization-link` 注册入口元数据；授权值只能由安全页提交并通过 AppDeploy secrets 绑定。页面只向同一配对返回有效链接。无有效链接时显示申请渠道，不能由网页直接生成平台授权页。链接、私有配对凭据和授权值均不能写入仓库。
