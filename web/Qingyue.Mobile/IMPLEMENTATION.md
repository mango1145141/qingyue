# 轻阅手机网页版 v1.3

## 实施清单

- 更新原 AppDeploy 应用 kindle-zftrvo，保留其后台邮箱授权、配对接口和现有浏览器设置。
- 首页：蓝色书本标识、与桌面同源每日一句、书籍/漫画切换搜索、EPUB 导入；不显示推荐。
- 四个独立页面：导入、书架、发送队列、想读；本地文件采用 IndexedDB，收藏/分类/记录可管理。
- 小文件在设备上修复，提供目录文字预览、修复版下载、邮件直推及系统分享。
- 邮件失败/未确认通过已有幂等发送与查询恢复；刷新后保留请求标识，避免重复寄送。
- 网站登录和 Amazon 网页发送在 Safari 外站继续，保持真实状态；50MB 内本机修复，50–200MB 通过大文件引导。
- 不修改桌面前端；手机源码与交付说明保存到 G:\chatgpt\轻阅，并同步到 GitHub web 目录。

## 发布前检查

- 已阅读平台约束和 api SDK 类型；未新增后台路由或变更私密授权。
- 只上传变更文件，完整重写文件用 content，局部改动用 diffs。
- 用已有 SVG 图标及程序化界面；没有用户上传二进制资源、没有源码中的 secret 值。
- 对账既有 tests/tests.json，将本次可见变化合并为最多五个流程；只保留一个 sanity。
- 邮箱设置、配对与原授权失败保护保留；不发送验收邮件。
- 编译、JSON 校验和无私密数据检查后再发布；发布后同一轮等待 QA 结束并处理错误。

## 验收覆盖

1. 示例 EPUB → 修复 → 下载 → 本机书架 → 刷新 → 文字预览 → 分享/邮件未连接保护。
2. 多文件队列、暂停/继续、损坏 EPUB、独立导航、记录删除确认。
3. 书籍/漫画查询编码、中文输入保护、想读添加搜索移除与持久保存。
4. 设置、手动修复、保存选项、深浅色/字号/减少动效、清理记录。
5. 双设备邮箱偏好配对、断开、匿名接口保护与授权失败提示（不寄信）。

## 手机授权 1.4

- 读取当前配对与发件邮箱对应的后端授权，不复用其他工作区授权。
- 安全提交页由 AppDeploy 管理工具生成；一次性链接仅存于已配对工作区私有记录，有效期与发件邮箱共同约束。
- `/api/mail/authorization-link` 仅用于维护者为已授权配对注册入口元数据；不接受邮箱授权码。平台授权值只通过安全页及 AppDeploy secrets 绑定。
- 无有效入口时，展示申请渠道及 163 授权获取路径；不制造不存在的自动授权。
- 发布前核对远端源文件、SDK 类型、授权状态及过期提示；验收不实际发送邮件。
