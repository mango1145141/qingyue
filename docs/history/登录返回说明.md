# 轻阅 2.1.1

## koz.moe 登录后自动返回

点击右上角“登录 koz.moe”后，在网站完成登录。轻阅确认登录成功，会自动收起漫画浏览窗口并激活轻阅主页，保留当前登录会话。

搜索漫画、浏览详情和选择卷数时，浏览窗口正常保持打开。如果搜索过程中需要重新登录，确认登录后也会先回到轻阅主页；原搜索词仍留在主页的漫画搜索框中。

已连接状态下再次打开 koz.moe 用于选卷或管理设置，会保持浏览窗口，不会把正常浏览误判为登录。

## 大文件从哪里发送

直接在轻阅主页拖入 EPUB 或点击“选择书籍”即可。开启自动发送时，修复后超过邮件限制、且不超过 200 MB 的文件会自动转到软件内的亚马逊上传窗口，无需事先打开亚马逊网站或再次手动选择文件。

首次使用或登录过期时，需要在该窗口完成亚马逊登录及验证码；已有有效会话时，软件自动选入修复版并发送。当前版本仍显示内嵌上传窗口，不是完全在主页后台静默上传。需要时可选择 Edge 备用入口。

关闭自动发送时，修复后在主页点击“发送到 Kindle”，同样自动选择发送通道。

“网页已提交”代表亚马逊已接收，随后仍需转换和 Kindle 联网同步。
