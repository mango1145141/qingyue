# 轻阅 1.9.0 · 为你选书与每日一句

## 使用

1. 关闭旧版，双击桌面「轻阅」，或运行 G:\chatgpt\轻阅-v1.9.0\轻阅.exe。
2. 品牌栏下方显示每日一句、作者和作品出处，可点「读原文」打开原文页面。
3. 在搜索框搜索书名、作者或题材。书库内 `/s/` 搜索页携带 `q` 的查询也会记录。
4. 首页「为你推荐」在导入区下方常驻显示十二本书的封面，继续向下滚动自动追加下一批十二本。悬停或用 Tab 聚焦会翻开作者与简介，点击「去书库搜索」会带上完整书名。推荐理由可在题材文字的提示中查看。
5. 「换一批」重新开始一轮推荐；「不感兴趣」会记住这本书，并从当前书架移除。
6. 「搜索记录」可查看最近 100 条、暂停记录，或清空全部记录并重置推荐。暂停后显示不同类型的精选书。
7. 推荐区不再折叠，检查修复时也保持显示。封面加载与翻页操作详见封面与翻页说明.md。

## 推荐范围

- 旧版没有保存可用于推荐的搜索记录。本版从今后的搜索开始积累，不会虚构旧记录。
- 推荐先使用内置精选书目，随后按题材加载 Open Library 在线书目，涵盖轻小说、科幻、悬疑推理、幻想冒险、文学小说、历史、哲学思考、心理与成长、自然科普。
- 根据识别出的书名、作者、题材关键词推测阅读口味，近期搜索权重更高。推荐点击带来的搜索权重较低，并补充其他题材的探索书目。
- 无法识别的查询会保留，但不会被强行归入某种偏好。推荐仅表示可能感兴趣，书库是否有对应版本由网站搜索结果决定。
- 内置简介与题材标签由应用编辑整理；在线简介来自公开作品元数据，可能为原文语言。优先显示返回的中文版本名称。没有简介时显示来源和查询提示。

## 每日名句

- 内置 19 条古典名句，按北京时间的日期轮换；同一天不因重新启动而变化。
- 程序持续打开时，会在跨日后一分钟内更新；休眠恢复或再次打开会使用当天日期。
- 离线也可更新名句；查看出处需联网。语录轮换至末尾后循环。
- 来源链接保留原文及作品信息；应用以简体中文呈现，节选处标明「节选」。

## 数据

- 搜索记录与“不感兴趣”列表仅在本机使用，由 Windows 用户加密机制保护，保存在本机 KindleBookRepair 数据目录。
- 最多保留 500 条查询，最近 180 天的查询参与推荐。十分钟内的相同查询去重，避免网页重定向重复计入。
- 本机推荐记录没有加入手机设置同步。在线推荐请求只使用识别出的通用题材标签；封面请求只使用封面编号，简介请求使用作品编号，不发送个人搜索原文、邮箱或书库账号。用户点搜索时仍会向所选书库提交书名。
- 既有邮箱连接、书库会话和同步配对沿用原保存位置。

## 构建范围

Windows 64 位自包含程序编译完成，不需要另装 .NET。已运行推荐、曲面及隔离 WPF 交互检查；未使用真实账号搜索、下载或发送邮件。
