# 轻阅 v2.1.2 · 在主页后台发送

## 使用方式

正常在轻阅主页拖入或选择 EPUB 即可。检查修复后，超过邮件大小限制的书籍会在后台交给亚马逊官方 Send to Kindle 上传，单本最高 200 MB。也可以在右上角“连接亚马逊”中开启“小文件也使用亚马逊网页发送”。需要在设置中开启自动发送；关闭自动发送时，检查完点击“发送到 Kindle”。

- 有效登录：保持在主页，后台准备文件、上传并等待接收确认，无需预先打开亚马逊网页。
- 初次登录、会话过期或验证码：打开官方操作窗口供本人完成登录/验证，确认登录后自动返回主页并继续上传。
- 网站控件变化、文件校验提示、旧的待发送文件或网络异常：主页提示原因，打开操作窗口处理；点击“继续自动上传”后返回后台。
- 主页进度卡提供“查看发送”和“稍后发送”。开始提交后，后者显示为“结束等待”，结果记为待确认，不会自动重新提交。
- 显示“亚马逊已接收”表示官方上传已被接收。亚马逊还需转换文件，Kindle 需联网同步；此时不会宣称设备已经收到。

## 保留的内容

沿用 AmazonBrowser-v1 登录资料，不要求重新配置发件邮箱。正文、目录与插画不经过降质处理。保留蓝色图标、搜索框、书架、推荐封面、翻页动效、想读清单和漫画登录返回功能。新增按钮使用原有按钮样式与统一动效；进度变化提供平滑过渡，并尊重“减少动效”设置。

选择“使用 Edge 继续”时，软件只控制自己启动的专用 Edge 窗口：登录或处理异常时显示，完成登录后隐藏并继续后台发送。软件运行期间可以复用该备用会话。两种浏览器的登录资料各自保存；重新启动后默认使用内置网页组件，若之前仅登录过备用 Edge，内置组件可能仍需首次登录。

## 实现与构建记录

内置上传使用 WebView2 控制器和从不显示的本机窗口，在需要操作时将同一个控制器移到操作窗口，避免启动上传时弹窗闪烁。窗口隐藏与控制器布局分别管理，依据微软官方 [控制器可见性说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2controller) 和 [ParentWindow 接口](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2controller.parentwindow)。

基于 G 盘 v2.1.1 最新源码构建。已完成 Release 编译与独立 EXE 打包；本次未使用真实亚马逊账号执行上传，登录与送达效果仍需在实际账号会话中确认。
