# 轻阅 2.0 · 个人书架与阅读偏好

本版基于最新的 Kimi 动效源码继续开发。保留首页结构、蓝色图标、顶部搜索、导入区域、推荐位置和现有翻书几何效果。新按钮复用现有按钮模板与弹簧动效。

## 六项新增功能

1. **我的书架**：点击导入区标题“我的书籍 ↗”。选入的 EPUB 会留在书架中，显示书名、作者、原书封面、检查结果和发送状态。可以按书名、作者、分类搜索，收藏书籍，并填写、保存分类。封面来自 EPUB；没有封面的文件会显示书籍占位图。修复后的文件可在书架中重新预览和发送。
2. **发送队列**：点击导入区右侧“发送队列”。每本书显示处理阶段与进度，支持暂停、继续、跳过和单本重试。修复与发送任务、失败原因会保存在 G 盘，重启后恢复。连接失败或邮箱明确暂时拒绝时，最多自动重试三次，间隔 30、60、120 秒。授权失败、附件错误等问题需修正后手动重试。发送结果不确定时会提示先确认收件情况，再由你决定是否重试。
3. **发送前预览**：修复结果卡增加“预览书籍”，书架和队列也可打开预览。支持封面、目录选择、正文、修复摘要、缺图与兼容性提示，以及处理与发送记录。设置中打开“发送前预览确认”，每本书会等待确认再发送；选择“稍后发送”的书保留在队列。默认关闭确认步骤，保持原来的自动发送习惯。正文使用纯文字预览，实际 Kindle 排版以设备为准。
4. **想读清单**：推荐封面翻开后，点击“＋ 想读”。在推荐区标题右侧“想读清单”查看收藏的书、封面和介绍，继续搜索或移出清单。收藏会参与推荐的题材和作者评分。
5. **推荐偏好**：设置中选择“熟悉、均衡、探索”，调整喜欢、排除的题材与中文优先。喜欢的题材提高推荐权重，排除的题材不会出现。修改后刷新推荐；原有每批 12 本与继续向下加载保留。
6. **外观与动效**：设置中选择浅色、深色、跟随系统；文字大小提供标准、大、更大；动效提供 Q 弹、轻柔、减少动效。默认沿用原来的浅色外观与 Q 弹参数，原有按钮和新按钮使用同一套设置。

## 保存与升级

- 桌面程序：`G:\chatgpt\轻阅-v2.0.3\轻阅.exe`
- 对应源码：`G:\chatgpt\轻阅-v2.0.3-源码`
- 书架记录与封面：`G:\chatgpt\轻阅数据\书架`
- 修复 EPUB：`G:\chatgpt\Kindle 修复`
- 原有邮箱设置、书库登录记忆和搜索记录继续使用原来的本机存储位置；想读清单与题材偏好保存在加密的阅读配置中。
- 此版开始记录新选入的书籍。之前生成的 EPUB 可以重新选入，加入书架。
- “邮件已提交”表示邮箱接受了邮件，Kindle 仍需联网并等待 Amazon 处理。
- 自动重试需要轻阅正在运行、队列未暂停、自动发送已开启，且发件邮箱已连接。
- 新版源码与程序独立存放，原 1.9.0 文件保留。桌面快捷方式已指向新版；请关闭旧轻阅，再从桌面“轻阅”打开。
