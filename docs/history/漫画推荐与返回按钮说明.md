# 轻阅 v2.1.4 · 漫画推荐与返回入口

## 界面

Z-Library 书库窗口的“返回轻阅”已从右下角移到右上角，使用现有蓝色主按钮样式。漫画与亚马逊窗口的同一入口也采用该样式。“确认登录”仍保留在旁边。原推荐区的布局、封面翻页、按钮弹簧动效保持原实现。

漫画混排在“为你推荐”中，封面下标有“漫画”和题材。翻开后显示作者与简介，点击“去漫画搜索”进入 koz.moe；普通书籍仍进入 Z-Library。想读清单中的搜索入口也会按类型打开对应网站。

## 推荐逻辑

初始加入 16 部漫画系列，包括海贼王、火影忍者、间谍过家家、葬送的芙莉莲、钢之炼金术师、死亡笔记、名侦探柯南、排球少年、灌篮高手、蓝色监狱、四叶妹妹、辉夜大小姐想让我告白、石纪元、进击的巨人、全职猎人和鬼灭之刃。

- 漫画与书籍共用同一份加密的搜索记录、想读清单、题材偏好和“不感兴趣”列表。
- 漫画搜索成功提交后记录搜索；使用相同的最近 180 天范围、30 天半衰期、推荐点击降权、想读与偏好加权进行排序。
- 没有明显漫画偏好时，每批 12 本保留少量漫画探索位置；有漫画偏好时，其题材与作者分数可以让更多漫画排到前面。已排除的题材和已标记的作品不会强行补回。
- 向下滚动继续加载。精选系列之后，Open Library 的漫画及相关题材分页书目也参与现有加载流程。
- 设置中可选择“漫画”“日常治愈”“运动竞技”“恋爱青春”等偏好或排除项。
- 搜索时需要网站登录，会保留漫画名；独立登录仍返回主页，搜索流程完成登录后继续搜索。

## 来源

书目与封面编号来自 [Open Library 搜索接口](https://openlibrary.org/dev/docs/api/search)，封面由现有缓存机制加载。精选系列展示代表性版本的封面，语种或卷次可能不同。短简介及题材是轻阅编辑说明，具体可用卷数以 koz.moe 搜索结果为准。

作者与系列信息同时参考 [VIZ 漫画分类](https://www.viz.com/manga-books/genres)、[海贼王](https://www.viz.com/one-piece)、[间谍过家家](https://www.viz.com/spy-x-family)、[排球少年](https://www.viz.com/haikyu)、[灌篮高手](https://www.viz.com/slam-dunk)与 [Kodansha 蓝色监狱](https://kodansha.us/series/blue-lock/)的官方介绍。
