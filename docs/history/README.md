## 使用

1. 关闭旧版，运行本文件夹里的 轻阅.exe。既有邮箱连接和书库配置会继续使用。
2. 右上角「设备同步」→「生成手机配对二维码」。
3. iPhone 相机扫描，在 Safari 打开，配对后设置即同步。若先在手机生成配对链接，也可粘贴到电脑版连接。
4. 链接 5 分钟内有效，一次连接后失效；只交给自己的设备。每份设置最多连接 8 台设备。可在任一端断开当前设备。
5. 手机已支持邮箱直推和分享到 Kindle 两种选择。手机独立邮箱连接需单独完成一次安全授权；电脑上的发件邮箱与偏好会继续同步。

## 第一次使用

1. 打开「轻阅.exe」，进入右上角「设置」。
2. 输入「发件邮箱」和「Kindle 接收邮箱」，点击「保存」。发件邮箱请使用你已在亚马逊认可的地址。
3. 软件会尝试使用电脑上经典版 Outlook 中已登录的同一个发件账号。如果没有可用登录，会显示一次性的连接引导。
4. QQ、Foxmail、163 和 Gmail 会自动识别服务，只需按官方页面的引导取得授权码并粘贴。其他邮箱可先在经典版 Outlook 中登录，然后回来重新检查。新 Outlook 暂不支持这种连接方式。
5. 连接完成后，把 .epub 文件拖进主窗口，等待检查、修复和发送提示。支持一次拖入多本书。

以后无需重新配置。关闭「修复后自动发送到 Kindle」后，可先查看检查结果，再点击发送。

## 从 Z-Library 找书

1. 点击主窗口右上角「登录 Z-Library」。默认入口已按你最新确认的地址改为 `https://zh.z-library.sk/`，也可以在书库窗口点击「更换网址」。旧入口已停用，保存过旧入口的配置会自动更新。
2. 在内嵌的网站页面完成账号登录和验证码。软件根据网站返回的状态确认登录；确认后返回主页，并显示搜索框。如果网站未自动返回，可点击「登录完成，返回主页」重新确认。
3. 首次连接成功后，软件会记住这个书库。以后重新打开软件，主页直接显示搜索栏；输入书名、作者或 ISBN，点击「搜索书籍」或按回车即可，无需先点击登录按钮。
4. 在软件内的网站结果页选择书籍的 EPUB 版本，点击网站自己的下载按钮。下载额度、访问限制和文件可用性由网站决定。
5. 完整下载并确认文件为 EPUB 后，软件自动检查、修复，并按原来的自动发送设置推送到 Kindle。开启「修复后自动发送到 Kindle」并连接发件邮箱，即可完成自动推送。

下载原书保存在 `G:\chatgpt\书籍下载`，修复版保存在 `G:\chatgpt\Kindle 修复`。下载中断或网页被误保存为书籍时，不会继续修复或发送。当前流程支持 EPUB；PDF 等格式暂不自动处理。

书库窗口关闭后会隐藏，未完成的下载可继续进行；退出整个软件会中断下载，因此退出前会有确认提示。登录会话保留在本机专用浏览器配置中，软件不会单独存储网站密码。1.3.4 延用 1.3.3 的网页配置，不清除已有网站会话。搜索栏会一直保留；网站若明确要求重新登录，软件会提示在网页中更新登录。更换书库网址后，需要首次连接新入口。

网页功能使用微软 WebView2 Runtime。当前电脑已检测到该组件；其他电脑若缺少，会显示微软安装入口。[微软分发说明](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)。

新功能已编译发布。尚未使用用户账号登录、下载书籍或验证 Kindle 实际收件；网站变更或区域网络限制可能影响登录与下载，可在书库窗口更新入口。

1.3.2 修正了格式筛选被网站拒绝后搜索退回首页的问题，采用网站要求的格式值。如果网站仍拒绝格式筛选，会保留书名、不带格式筛选重新搜索一次；请在结果中选择 EPUB 下载。

1.3.1 已修正搜索时误打开登录检查页面的问题：搜索通过网站自己的表单提交，误跳转时返回书库并恢复一次搜索。网站反复跳转时会显示提示，不会无限重试。升级时关闭旧版，打开 1.4.1 即可。

邮箱地址可以先保存，授权也可以稍后连接。更换发件邮箱需要重新连接；更换 Kindle 接收邮箱会保留原发件账号的连接。

## 为什么首次还需要连接？

亚马逊认可发件地址，表示它允许接收这个地址发来的书籍。软件仍需要发件邮箱允许它发信，才能代你寄出附件。连接凭据会在本机加密保存；连接检查只验证登录，不会发送测试邮件。

官方说明：[QQ 邮箱连接说明](https://cloud.tencent.com/document/product/1270/55456)、[Gmail 应用专用密码](https://support.google.com/accounts/answer/185833?hl=zh-Hans)、[经典版与新版 Outlook 功能比较](https://support.microsoft.com/en-us/outlook/getstarted/feature-comparison-between-new-outlook-and-classic-outlook)。

## 修复与发送结果

- 修复后的书籍保存在 `G:\chatgpt\Kindle 修复`，原文件保留。
- 软件补齐未登记的图片资源，并按 EPUB 规范重打包。输入格式为 EPUB。
- 如果书内引用的图片文件本身缺失，会显示提示；补登记无法恢复缺失的原始图片。
- WebP 图片会显示兼容性提示，当前版本不会自动转换图片格式。
- 「邮件已提交」表示发件邮箱接受了邮件；Outlook 方式则显示「已交给 Outlook 发送」。Kindle 收到书籍还需要亚马逊处理和设备联网同步。
- 发件账号授权失败或发送失败时，会显示下一步提示，修复后的书籍仍然保留，可重试发送。

## 数据保存

邮箱配置保存在当前 Windows 用户的 `%LOCALAPPDATA%\KindleBookRepair\settings.json`。授权码由 Windows 当前用户加密保护。不要把授权码填写到其他文本文件或发给他人。

## 源码构建

需要 .NET 10 SDK 和 Windows 桌面构建组件。

```powershell
dotnet publish .\EpubKindleFix.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

输出位于 `bin\Release\net10.0-windows\win-x64\publish\`。邮件组件为 MailKit，许可附在发行包内。
