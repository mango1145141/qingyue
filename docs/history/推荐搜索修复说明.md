# 轻阅 v2.1.3 · 首次推荐搜索与翻页状态修复

## 本次调整

- 首次点击推荐卡片“去书库搜索”时，先记录搜索意图与书名，再显示书库窗口。窗口首次加载不会同时启动默认登录流程。
- 登录与搜索使用请求编号，过时的初始化任务不能覆盖新的搜索词或重新导航。
- 搜索过程中收到登录成功消息，继续保留书库结果窗口；仅独立登录流程自动返回主页。
- 网站需要重新登录或暂时没有搜索表单时保留书名，后续回到书库可继续提交。
- 点击卡片搜索时清理悬停与操作按钮的残留焦点。主页失去活动状态时收起书页；返回主页时重新同步实际鼠标位置，恢复的按钮焦点不会把书页锁在展开状态。
- 书籍卡片卸载时解除窗口事件订阅，保留推荐区的虚拟滚动与现有翻页几何、弹簧参数、封面和按钮动效。

## 版本与构建

基于 G 盘轻阅 v2.1.2 最新源码，保留主页后台上传、漫画搜索、想读清单及现有前端布局。

已完成 Release 编译与独立 EXE 打包。本次未运行真实 Z-Library 账号的交互检查；实际网站登录、搜索与返回的表现仍需在真实会话中确认。
