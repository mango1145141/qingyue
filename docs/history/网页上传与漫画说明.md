# 轻阅 2.1.0 · 亚马逊网页上传与漫画搜索

## 亚马逊上传

- 首页右上角新增“连接亚马逊”。在轻阅内的亚马逊官方页面完成登录；验证码、二次验证由你在官方页面填写。
- 修复后的 EPUB 超过邮件附件限制时，自动改用 Send to Kindle 网页上传，单本最高 200 MB。超过 200 MB 的文件仍会修复和保存，发送队列会显示大小限制。
- 小文件沿用已配置的邮件直推。如果希望所有书都通过网页发送，可在亚马逊窗口开启“小文件也使用亚马逊网页发送”。
- 自动上传依次选入本次修复版、加入账号书库、点击官方发送按钮并等待接收结果。上传窗口显示文件名、大小和进度。
- 首次使用需要登录，之后沿用本机网页会话；亚马逊令登录失效时需重新登录。
- 内嵌登录不兼容或自动操作失败时，点击“使用 Edge 继续”。轻阅打开独立的 Edge 上传窗口；你在那里登录，软件继续选入文件和上传。该专用窗口与平时的 Edge 资料分开。
- 点击“稍后发送”，书籍保留为“等待网页发送”；点击发送队列中该书的“发送 / 重试”继续。当前会话暂停自动发送，其他书仍可检查修复。
- 如果上传已经开始，关闭上传窗口或结束等待会记录为“发送结果待确认”。确认亚马逊书库和 Kindle 的实际结果后再重试。
- “网页已提交”表示亚马逊已接收请求，尚需亚马逊转换、Kindle 联网同步；不代表设备已下载完成。

## koz.moe 漫画

- 首页上方新增独立的大漫画搜索栏，支持输入漫画名、作者后点击“搜索漫画”，也支持 Enter。
- 右上角新增“登录 koz.moe”。在网站中输入账号密码，登录会话保留在本机，失效后重新登录。
- 搜索使用网站的实际 GET 表单（/list.php，参数 s），将输入的漫画名直接提交到结果页；登录后保留待搜索内容。
- 在漫画详情页选择卷数，使用网站自带的“推到 Kindle”。首次使用请在 koz.moe 网站里配置、验证 Kindle 地址。
- 网站推送的额度、格式、进度由 koz.moe 管理；轻阅不把打开网页当作推送成功。
- koz.moe 页面说明其站内推送会将文档压到 50 MB 以下，可能与保留原图画质的目标不同。可以选择下载 EPUB，交给轻阅检查修复，再用亚马逊网页上传。
- 下载完整的 EPUB 后，轻阅自动保存到 G:\chatgpt\书籍下载，并接入原有检查、修复与发送队列。MOBI、ZIP 等格式未接入自动修复，可使用网站本身的推送入口。

## 界面与数据

- 保留原有蓝色书本图标、每日一句、推荐区、翻书效果和想读切换。
- 新搜索框沿用书籍搜索框的尺寸、中文输入和留白。
- 新按钮沿用原有弹簧动画和按钮模板；顶部空间不足时工具按钮自动换行。
- 原有邮箱设置、书架、想读、推荐偏好继续使用。
- 账号密码直接在官方或 koz.moe 页面填写。轻阅不读取或上传密码，网页会话保存在当前 Windows 用户的本机资料目录；源码和发布包不包含会话资料。
- 书架增加“网页已提交”和“等待网页发送”，支持查看记录、单本继续和重试。

## 构建记录

Windows x64 自包含发布。源代码已编译成功。未进行账号登录后的实际上传或发送；首次使用需由你完成网站登录。网页自动化依赖网站当前页面，遇到页面变化时会保留修复版并提供手动操作或 Edge 入口。
