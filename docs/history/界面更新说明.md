# 轻阅 1.6.3 · 清晰度改进

卡片阴影与前景内容拆分，文字和图案在前景正常绘制。启用首页布局像素对齐，并在淡入与回弹结束后释放动画渲染状态。

# 轻阅 1.6.1 · 首页与动效

## 首页

- 顶部先显示蓝色书本图标、轻阅名称和功能入口。
- 「每日一句」移到品牌栏下方，正文从 13 提高到 25 号，使用深蓝灰文字、作者行和细竖线，取消原来的横幅底色。
- 搜索框保留在上方，文字与按钮继续保持较大尺寸。
- 选择书籍改为紧凑的横向卡片；推荐位于导入入口之后，页面按阅读、找书、导入与推荐形成层次。
- 首页设计预览使用演示书单与偏好，不读取用户搜索记录、邮箱或账户。

## 动效

- 软件内按钮共用悬停、按下、松开状态过渡；点击另有轻微回弹，鼠标和键盘触发均使用统一反馈。
- 按下约 70 毫秒，悬停与回弹约 160 毫秒；使用缓动曲线。
- 邮箱设置、连接引导、设备同步、搜索记录等窗口内容淡入；推荐切换与修复结果使用约 220 毫秒的淡入和轻微上移。
- 推荐展开与收起有高度过渡；设置开关有滑动与颜色过渡；帮助面板打开、关闭均有淡入淡出。
- 动画不会在搜索、保存、修复或发送之前加入等待。WebView2 内的第三方网页及系统文件选择器由各自界面处理。
- 窗口与卡片进入、推荐展开及按钮回弹会遵循 Windows 客户区动画开关。开关滑块仍使用短过渡。

Windows 64 位自包含版本编译成功，并导出原生 WPF 静态设计预览。本次未执行逐按钮交互测试、网站搜索或真实邮件发送。
