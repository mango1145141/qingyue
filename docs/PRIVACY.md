# 数据与隐私

- 邮箱设置在当前用户的 `%LOCALAPPDATA%\KindleBookRepair\settings.json` 中保存，授权凭据使用 Windows 当前用户 DPAPI 保护。
- 书库登录会话保存在本机专用 WebView2/浏览器配置中；源码仓库不包含这些配置。
- 推荐使用本机搜索记录、想读清单及题材偏好，记录按现有实现加密保存。
- 下载、修复文件与封面缓存默认在 `G:\chatgpt` 下保存，不纳入 Git 版本管理。
- 主动配对手机时，邮箱地址和偏好会同步到原项目的 AppDeploy 服务；授权和书库会话留在各自设备。
- Open Library 的在线书目与封面请求会访问外部接口；网站搜索、邮箱发送和网页上传分别向对应服务提交必要数据。
- 报告问题前，请从截图、日志和文字中移除邮箱、授权码、书库账号和配对信息。
